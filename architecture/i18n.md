# i18n

## Purpose

Render all UI copy and dates in the user's chosen language (English or Russian).

## Behavior

- Settings exposes a language tile with three choices: **System default**, **English**, **Русский**. Selecting one updates `LocaleController`, which writes to `shared_preferences` and sets Riverpod state; `MaterialApp.locale` rebuilds immediately — no restart required.
- "System default" passes `locale: null` to `MaterialApp`, letting Flutter resolve the device locale; it falls back to English for any device language other than Russian.
- Date labels (day-strip header, heatmap month abbreviations) reformat via `intl` `DateFormat` using the active locale name (`Localizations.localeOf(context).toString()`): weekday/month ordering and Cyrillic month forms follow the locale automatically.
- The reminder notification body ("Time to check in" / "Пора отметиться") is localized: `ReminderCoordinator` resolves it from `AppLocalizations.of(context)` using its own widget `BuildContext` and passes it to `NotificationService.syncSchedule`; a locale change triggers a resync so queued notifications pick up the new language.

## Code map

**Hand-written:**

- `lib/l10n/app_en.arb` — English ARB template; drives codegen; all string keys are defined here
- `lib/l10n/app_ru.arb` — Russian ARB; full coverage of all keys; plurals use ICU `one/few/many/other` categories
- `l10n.yaml` (repo root) — codegen config (arb-dir: `lib/l10n`, template: `app_en.arb`, output: `app_localizations.dart`, `nullable-getter: false`)
- `lib/ui/core/locale_controller.dart` — `AppLocale` enum (`system`, `en`, `ru`); `LocaleController` Riverpod notifier reads the persisted token on first build and exposes `set(AppLocale)` which persists and updates state
- `lib/data/repositories/settings_repository.dart` — `SettingsRepository`: reads/writes the `'locale'` key in `shared_preferences`; the sole persistence boundary for the chosen locale
- `lib/ui/settings/settings_screen.dart` — `Consumer` wrapping the language `ListTile`; taps open a `SimpleDialog` with all three `AppLocale` options and dispatch `localeControllerProvider.notifier.set(...)`
- `lib/main.dart` — `HabbitsApp.build` watches `localeControllerProvider`; wires `locale: appLocale.locale`, `localizationsDelegates: AppLocalizations.localizationsDelegates`, and `supportedLocales: AppLocalizations.supportedLocales` into `MaterialApp`
- `lib/ui/widgets/recent_days_list.dart` — `_label` resolves `localeName` from `Localizations.localeOf(context)` and passes it to `DateFormat.MMMEd` for locale-aware day labels
- `lib/ui/widgets/heatmap_grid.dart` — `monthLabels` passes `localeName` to `DateFormat.MMM` for locale-aware month abbreviations in the heatmap header
- `lib/ui/core/reminder_coordinator.dart` — `ref.listenManual(localeControllerProvider, ...)` triggers a notification resync on locale change; it resolves `AppLocalizations.of(context).reminderBody` for the notification body text

**Generated (committed, do not edit by hand):**

- `lib/l10n/app_localizations.dart` — abstract `AppLocalizations` base class; `AppLocalizations.of(context)` accessor; `supportedLocales` (`[Locale('en'), Locale('ru')]`); `localizationsDelegates` list including `GlobalMaterialLocalizations` and `GlobalCupertinoLocalizations`
- `lib/l10n/app_localizations_en.dart` — `AppLocalizationsEn`; English string implementations
- `lib/l10n/app_localizations_ru.dart` — `AppLocalizationsRu`; Russian string implementations; plural methods call `intl.Intl.pluralLogic` with `locale: localeName` and four Russian plural categories
- `lib/ui/core/locale_controller.g.dart` — Riverpod-codegen output for `localeControllerProvider`

## Invariants

- No user-facing string is hard-coded in widgets; all copy comes from `AppLocalizations.of(context)`. The brand name "Habbits", habit names (user data), and JSON keys are intentionally not in ARB.
- Russian plurals use ICU `one/few/many/other` categories via `intl.Intl.pluralLogic(count, locale: localeName, one:..., few:..., many:..., other:...)` — not English `count == 1` logic (`lib/l10n/app_localizations_ru.dart` `replaceBody`, `importedHabits`).
- Date formatting is locale-aware: `DateFormat.MMMEd(localeName)` and `DateFormat.MMM(localeName)` from the `intl` package; no date string is hard-coded. Date symbol data for `en` and `ru` is loaded by `GlobalMaterialLocalizations.delegate` without a separate `initializeDateFormatting` call.
- The chosen locale persists across launches: `SettingsRepository.writeLocaleToken` stores a stable string token (`system`|`en`|`ru`) under `shared_preferences` key `'locale'`; `LocaleController.build` reads it synchronously on first watch.
- The backup file format is locale-independent; importing someone else's backup never changes the user's language preference.

## Known edges

- The Android notification channel name (`'Habit reminders'`) is hard-coded English: `NotificationService._channelName` (`lib/data/services/notification_service.dart`) is a `const` and is not localized. This is a distinct localization gap from the per-notification body (which is localized). See also `reminders.md` Known edges.
